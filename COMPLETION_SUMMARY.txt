================================================================================
WHAT IT DOES
================================================================================

1. Discovers images in your folder
2. Sends them to GPT-5 API in intelligent batches of 25
3. Receives back:
   - Raw OCR (exactly as extracted)
   - Corrected OCR (cleaned and grammatically correct)
   - NER (Named Entity Recognition for 9 entity types)
   - Metadata (document type, confidence, language, quality, etc.)
4. Validates all JSON responses
5. Saves results as {filename}.json
6. Tracks progress with token counts and cost estimation
7. Handles failures with automatic retries
8. Persists state to prevent re-processing

================================================================================
STATE MANAGEMENT
================================================================================

The system creates 3 tracking files:

1. processed_files.csv
   - Tracks which files were processed
   - Prevents re-processing on subsequent runs
   - Can be deleted to start fresh

2. error_log.json
   - Detailed information about failures
   - Request IDs for debugging
   - Why each failure occurred

3. ocr_processor.log
   - Verbose processing log
   - All events with timestamps

================================================================================
PROCESSING MODES
================================================================================

When you run the processor, choose from:

1. Process new images only
   → Skip already-processed files (RECOMMENDED)

2. Reprocess everything
   → Reset state and process all images

3. Retry failed files only
   → Reprocess files marked as ERROR

4. Continue where we left off
   → Resume interrupted processing

5. Exit

================================================================================
CONFIGURATION HIGHLIGHTS
================================================================================

Essential settings in config.txt:

OPENAI_API_KEY=sk-your-key           # Your API key
INPUT_FOLDER=/path/to/images         # Where images are
OUTPUT_FOLDER=/path/to/images        # Where JSON goes (can be same)
MODEL=gpt-5-mini                     # gpt-5, gpt-5-mini, or gpt-5-nano
BATCH_SIZE=25                        # Images per batch
MAX_RETRIES=3                        # Retry attempts

Everything is configurable!
